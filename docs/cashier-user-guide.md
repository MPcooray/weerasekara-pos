# Cashier user guide

## Customer and sale

Search by name, phone or customer ID before registering someone. If a possible duplicate appears, inspect it; do not merge automatically. Only name and a valid phone number are needed. Create a visit when the customer arrives.

At checkout select the correct customer and products, confirm quantities and totals, then submit once. If the connection fails after submission, refresh and check invoice history before retrying. Record each cash, card or bank transfer with the actual amount and reference. The displayed outstanding balance must match what the customer still owes.

## Receipts and collection

Open print preview and choose A4 or 80 mm, then use the browser/system print dialog or Save as PDF. Direct Bluetooth printing is not supported. Confirm order identity and customer before collection. If a balance remains, request manager authorization; do not record a fake payment.

At shift end, compare the payment-method report to till/card/bank evidence and report differences immediately. Customer notes must remain factual and necessary.
