# Owner user guide

Sign in with your own account; never share the owner credential. The owner can access all operational areas.

## Daily review

Open Dashboard and compare today's invoiced sales, payments, refunds and outstanding balances. In Reports choose the Colombo date range; distinguish sales from money received, and export CSV when required. Review recent transactions, low stock and pending quotations.

## Administration

Configure only genuine business/contact/registration details in branding. Create a separate employee for each person with the least-privileged role. Deactivate departed staff and reset compromised credentials immediately. Use audit records for investigation; never edit the database ledger.

## Exceptions

Approve returns/refunds only against the original invoice. A credit note adjusts the sale; a refund records money returned. Manager collection override with a balance does not mark an invoice paid. Review these exceptions daily.

At close, reconcile payment-method totals with cash/card/bank evidence and confirm backup health. Escalate any mismatch before adding corrective entries.
