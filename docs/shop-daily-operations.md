# Shop daily operations

## Opening

1. Confirm the site uses HTTPS, API status is healthy and the latest backup is successful and off-server.
2. Sign in with individual accounts; confirm printer paper and browser/system printing on the day's devices.
3. Review overdue orders, low stock, outstanding balances and pending quotations.

## During trade

Search before creating customers. Record visits and clinical work under the correct user. Confirm price/discount/tax before checkout. For an uncertain network result, inspect the record before retrying. Record real payment methods/references. Keep order and supplier statuses current; require QC before collection. Process returns only against original invoice lines.

## Closing reconciliation

1. Set the report to today's Asia/Colombo date.
2. Compare invoiced sales separately from payments received.
3. Match cash, card and bank-transfer totals to external evidence.
4. Review refunds, credits, discounts, outstanding balances, stock corrections and collection overrides.
5. Resolve or escalate differences; never directly alter financial or stock tables.
6. Confirm backup success/age, sign out and secure printed/exported customer information.

## Incident procedure

For an outage, preserve the screen/message and time; do not repeatedly submit financial actions. For a mismatch, stop affected entry and contact the manager/owner. For suspected compromise, disable/reset the account, rotate relevant credentials and review audit evidence. Restore only into a new database using the documented recovery procedure; validate it before switching the application.
