# Optometrist user guide

Search and open the customer, review visit and prescription history, then create an examination. Enter OD/OS values carefully within the configured ranges. Save a draft while incomplete; finalization makes the clinical record immutable. Correct a finalized result by creating a superseding revision, never by changing history.

Use prescription preview to verify customer, date, values, PD and notes before browser print/PDF. Create a standalone optical order from a finalized prescription when needed; invoice and payment data is intentionally unavailable to this role. At quality check, verify prescription, lenses, frame and fitting, add remarks, and record QC only when every check is complete.

Do not place unrelated sensitive information in notes. Lock or sign out when leaving the device and report suspected account access immediately.
